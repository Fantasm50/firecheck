# Дизайн базы норм (двухслойная модель)

Создано: 2026-10-10. Статус: каркас. Содержимое слоя 2 **не заполнено**: нужен официальный текст приказа МЧС № 525 от 14.07.2026 (приложение с формой).

> Достоверность: реквизиты приказа (№ 525, рег. Минюста № 88269 от 15.09.2026) взяты с klerk.ru и ppt.ru. Дата вступления в силу противоречива в источниках (26.09.2026 и 01.10.2026 как даты в новостях): проверить по тексту на publication.pravo.gov.ru. Ни одного контрольного вопроса листа я не видел, поэтому ни один не вписан.

## Идея

| Слой | Что хранит | Источник | Зачем |
|---|---|---|---|
| 1. Требования | Обязательные требования ПБ для типа объекта | ППР № 1479, 123-ФЗ, своды правил, ГОСТы (проверить редакции) | Полнота: что могут проверить |
| 2. Метка листа | Какие требования попали в вопросы листа № 525 | Приложение к приказу № 525 | Приоритет: что проверят в первую очередь |

Пункт 2 приказа № 525: проверка не ограничивается вопросами листа. Поэтому слой 1 главный, слой 2 только повышает приоритет.

## Структура файлов

```
norms/
  requirements/        # layer 1, one YAML file per topic
    evacuation.yaml
    fire_alarm.yaml
    ...
  checklist_525.yaml   # layer 2, questions of the official form
  scales.yaml          # S, O, D scales with sources
```

## Схема записи (layer 1)

```yaml
- id: EVAC-001
  title: "Evacuation exits are free and not locked"   # plain-language check
  source: "ППР № 1479, п. ?"        # exact point: TO BE VERIFIED in official text
  source_edition: "?"               # edition date, norms change
  applies_to: [production, warehouse]
  in_checklist_525: null            # id from checklist_525.yaml, or null
  s: null                           # severity, needs justification
  o: null                           # occurrence
  d: null                           # detectability
  verified: false                   # becomes true after checking the primary text
```

## Схема записи (layer 2)

```yaml
- id: Q525-01
  question: "?"                     # copy verbatim from the order
  norm_refs: ["?"]                  # inspector fills norm details in the form
  requirement_ids: []               # links to layer 1
```

## Правила

1. Пункт попадает в базу только с `verified: true` (сверен по первоисточнику).
2. Поле `source` без точного пункта запрещено для продакшена.
3. Нормы версионируются: меняются файлы, а не код.
4. Слой 2 заменяется целиком при выходе новой формы; слой 1 не трогается.

## Влияние на отчёт

- Индекс готовности считается по слою 1 (полнота).
- Отдельный показатель: «покрытие вопросов листа № 525» (сколько из ~20 закрыто).
- Топ-5 нарушений: сортировка по RPN, при равенстве выше те, что в листе.

## Что показал текст приказа № 525 (прочитан 2026-10-10)

Источник: `document.pdf` (скан, распознан OCR; формулировки в таблице шумные, сверить с оригиналом).

1. **27 вопросов**, а не «около 20». Первые 4 общие (условие соответствия, декларация, обучение и режим), 5–27 отраслевые, почти все ссылаются на разделы ППР № 1479 по номерам пунктов. Вопросы записаны в [checklist_525.yaml](../checklist_525.yaml).
2. **Для производства и склада** релевантны: Q1–Q4, Q6 (теплоснабжение), Q12 (производственные объекты, п. 121–166 ППР) или Q17 (хранение, п. 286–307), Q19 (огневые работы), Q21 (инструкции), Q22 (первичные средства пожаротушения). Это 9 вопросов из 27.
3. **Риск для проекта.** В сноске сказано, что **ППР № 1479 действуют до 31.12.2026 включительно**. Приказ № 525 при этом ссылается на них по номерам пунктов. Что придёт на смену с 2027 года, я не подтвердил (источники не называют акт). Демо в декабре 2026, защита летом 2027: слой 1 надо строить с расчётом на смену ППР. Если номера пунктов изменятся, привязка слоя 2 тоже.
4. Сроки действия из сносок (DOCX): ППР № 1479 до 31.12.2026; пост. № 1464 (оснащение АУПТ, АПС, СОУЭ) **до 01.03.2027**; приказ № 1173 (системы передачи извещений о пожаре) до 28.02.2029; приказ № 1120 (обучение по ПБ) до 01.09.2031. Два документа из четырёх истекают в первой половине 2027 года.
5. **Перепроверка по DOCX (2026-10-10):** количество вопросов (27), диапазоны пунктов ППР и реквизиты приказа совпали с PDF. Исправлены две ошибки моей первой расшифровки скана: (а) решение Совета ЕЭК № 40, а не № 403; (б) пункты «2-4, 7, 8, 10, 13, 14, 16, 18-20, 24» относятся к требованиям приказа МЧС № 1173, а не к пост. № 1464. Вопрос 3 (декларация ПБ) подтверждён. Дата вступления приказа № 525 в силу в тексте не указана.
5. Вопросы листа в основном «Выполняются ли требования к...»: это ссылки на целые разделы ППР, а не отдельные проверки. Конкретные пункты (слой 1) придётся выписывать самим из ППР, в разделе 121–166 пунктов 46, но **читая текст, видно, что почти все отраслевые** (спички, древесные плиты, электростанции, полиграфия). Универсальных около 11. Поэтому слой 1 для производства собран из нескольких разделов ППР: общие п. 2–60, территория, теплоснабжение, общие пункты производства, огневые работы, инструкции, огнетушители. Первый черновик: [requirements_production.yaml](../requirements_production.yaml), 63 пункта.
