# Анализ экспертного исследования

Скрипт считает всё, что задано в разделе 8 [протокола](../../expert-study-protocol.md): согласованность экспертов (W Кендалла), сравнение правил ранжирования с экспертами (τ-b, ρ, совпадение топ-5 и топ-10, бутстреп-интервалы) и разницу между черновыми и экспертными баллами. Нужен только Python из папки проекта: дополнительных пакетов скрипт не требует.

## Файлы

| Файл | Что это |
|---|---|
| `stats.py` | Формулы: средние ранги, τ-b, ρ, W Кендалла с χ², медиана с округлением вверх |
| `analyze.py` | Загрузка и проверка ответов, правила (а), (б), (в), бутстреп, отчёт |
| `make_synthetic.py` | Синтетические ответы для пробного прогона (не данные!) |
| `data/synthetic/` | Синтетические ответы 8 «экспертов» |
| `synthetic-report.md` | Отчёт по синтетике от 2026-11-18 |

## Как заполнить ответы экспертов

Создайте папку, например `study/data/real/`, и в ней два файла CSV (можно сделать в Excel: «Сохранить как» → CSV UTF-8). Образец — файлы в `data/synthetic/`.

1. `rankings.csv` — этап 1. Одна строка на эксперта: `expert,category,years`, затем 20 столбцов с кодами ситуаций (GEN-019, GEN-020, …). В каждой ячейке — место ситуации от 1 (устранять первой) до 20, без повторов.
2. `scores.csv` — этап 2. Одна строка на эксперта и ситуацию: `expert,situation,s,o,d`, баллы от 1 до 5.

В столбце `expert` — только код (Э01, Э02…), без имён.

## Как запустить

Все команды выполняются в Терминале из папки проекта.

1. Пробный прогон на синтетике (проверить, что всё работает):
   ```bash
   .venv/bin/python -m study.analyze study/data/synthetic
   ```
   Отчёт появится прямо в Терминале.
2. Анализ настоящих ответов с сохранением отчёта в файл:
   ```bash
   .venv/bin/python -m study.analyze study/data/real --out study/report.md
   ```
3. Если в ответах ошибка (повторный ранг, балл 6, пропущенная ситуация), скрипт не считает, а перечисляет, что исправить.

## Как проверить сам скрипт

```bash
.venv/bin/python -m pytest tests/test_study.py
```

Тесты сверяют формулы с примерами, посчитанными вручную, и с табличными значениями χ², проверяют, что правило (б) совпадает с порядком в сервисе и что одинаковые эксперты дают W = 1.
